# 💰 Juros: Simples

## 📌 Conceitos Básicos

Antes de entender os tipos de juros, é importante conhecer os termos fundamentais:

| Símbolo | Nome              | Descrição                                                             |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `C`     | **Capital**       | Valor inicial investido ou emprestado (também chamado de _Principal_) |
| `i`     | **Taxa de juros** | Percentual cobrado ou rendido por período                             |
| `n`     | **Tempo**         | Número de períodos (meses, anos etc.)                                 |
| `J`     | **Juros**         | Valor monetário gerado ao longo do tempo                              |
| `M`     | **Montante**      | Valor total ao final (Capital + Juros)                                |

---

## 📐 Juros Simples

### O que são?

Nos **juros simples**, os juros são calculados **sempre sobre o capital inicial**. O valor dos juros é o mesmo a cada período — ele não cresce sobre si mesmo.

> 💡 _Pense como um aluguel fixo: você sempre paga o mesmo valor por mês._

### Fórmulas

$$J = C \times i \times n$$

$$M = C \times (1 + i \times n)$$

### Exemplo prático

> Você investe **R$ 1.000,00** a uma taxa de **5% ao mês** por **3 meses**.

$$J = 1000 \times 0{,}05 \times 3 = R$\ 150{,}00$$

$$M = 1000 + 150 = R$\ 1.150{,}00$$

### Características

- Os juros são **lineares** (crescem de forma constante).
- Usado em: financeiras de curto prazo, alguns empréstimos pessoais, multas.
- **Vantagem**: simples de calcular.
- **Desvantagem**: menos rentável para investimentos longos.
