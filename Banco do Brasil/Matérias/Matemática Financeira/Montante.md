## 🏦 Montante

### O que é?

O **Montante** é o valor **total** ao final de uma aplicação ou dívida. Ele representa a soma do capital inicial com os juros acumulados.

$$M = C + J$$

### Resumo das fórmulas do Montante

|Regime|Fórmula do Montante|
|---|---|
|Juros Simples|$M = C \times (1 + i \times t)$|
|Juros Compostos|$M = C \times (1 + i)^t$|

### Como encontrar o Capital a partir do Montante?

$$C = \frac{M}{(1 + i \times t)} \quad \text{(Simples)}$$

$$C = \frac{M}{(1 + i)^t} \quad \text{(Compostos)}$$
