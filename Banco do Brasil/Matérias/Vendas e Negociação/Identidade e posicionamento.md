
## Identidade Corporativa

A identidade corporativa é um conjunto de elementos que formam a imagem de uma empresa e que a diferencia das outras no mercado. Esses elementos podem incluir nome, logotipo, cores, tipografia, slogan, missão, valores, entre outros.

Na administração pública, a identidade corporativa é utilizada para transmitir a imagem de órgãos, instituições e projetos governamentais.

Para melhor compreensão, segue uma tabela com alguns exemplos de elementos que compõem a identidade corporativa de uma empresa:


| **Elemento** | **Descrição**                                       |
| ------------ | --------------------------------------------------- |
| Tora         | Símbolo visual que representa a empresa             |
| Núcleos      | Paleta de cores que identifica a empresa            |
| Ponta        | Fontes utilizadas para a comuna                     |
| Lema         | Frase de impacto que comunica os valores da empresa |
| Missão       | Propósito da empresa                                |
| Valores      | Princípios que norteiam a atuação da empresa        |
